## Overview

## Overview

A modern developer portfolio focused on backend engineering, automation systems, and reliable software design.

This portfolio showcases projects, technical skills, and development philosophy through a clean interface inspired by terminal workflows and developer tooling. The project was also developed as a part of my AI Web Development internship work, with a focus on exploring AI-assisted website creation and modern deployment workflows.

The goal was to create a portfolio that feels lightweight, readable, and practical while highlighting real engineering work.

Live Site: https://pydportfolio.vercel.app

---

## Features

- Minimal and developer focused UI
- Terminal inspired interactions and navigation
- Responsive layout across desktop, tablet, and mobile
- Project showcase with detailed technical focus
- Sections for About, Skills, Projects, and Contact
- Fast deployment and optimized delivery through Vercel

## Design Philosophy

The portfolio follows a terminal inspired aesthetic with an emphasis on clarity and usability.

Key principles:

- Quiet and efficient interface design
- Readability over excessive visual effects
- Simple navigation and lightweight experience
- Focus on systems, tooling, and engineering work
